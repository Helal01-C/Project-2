# My Kitchen

A responsive dinner-only recipe website built with HTML, CSS, vanilla JavaScript, JSON, and LocalStorage.

## Run locally
Open the `My Kitchen` folder in VS Code and launch `index.html` with Live Server. A local server is required because recipes are loaded from `data/recipes.json`.

## Features
- 30 dinner recipes with ingredients, nutrition and detailed cooking steps
- Search, combined filters, sorting, categories and related recipes
- Persistent favorites, ingredient checks and cooking-step progress
- Responsive navigation and image-error fallback
